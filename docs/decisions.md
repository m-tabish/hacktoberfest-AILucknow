# Decisions Log

Record implementation decisions here as they are made. This file is intended for judges and future contributors; document the reason, evidence, alternatives considered, and observed trade-offs rather than listing libraries alone.

## Decision record template

### [Date] Decision title

- **Context:** What requirement or failure prompted the decision?
- **Decision:** What did we choose?
- **Evidence:** Which public validation slice, timing, memory, or reproducibility result supports it?
- **Alternatives:** What did we consider, and why did we not choose it?
- **Trade-offs:** What became better or worse?
- **Revisit when:** What evidence would justify changing this choice?
